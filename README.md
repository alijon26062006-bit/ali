# Личный сайт v1 (брутализм)

Простой статический сайт для публикации на GitHub Pages.

Содержимое репозитория:
- `index.html` — главная страница
- `styles.css` — стили
- `app.js` — скрипты
- `assets/` — изображения и другие ресурсы

Автоматический деплой настроен через GitHub Actions: при пуше в ветку `main` workflow соберёт артефакт и опубликует сайт на GitHub Pages.

Шаги для публикации:
1. Создайте репозиторий на GitHub.
2. Свяжите локальную папку с удалённым репозиторием и запушьте в `main`:

```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <URL_репозитория>
git push -u origin main
```

3. Подождите завершения workflow в Actions — сайт будет опубликован автоматически.

Если нужен собственный домен, создайте файл `CNAME` в корне репозитория с именем домена или укажите домен в настройках GitHub Pages.

Если хотите, могу добавить `CNAME` или настроить деплой в другую ветку — скажите, какой домен/ветку предпочитаете.
